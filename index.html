Java or Bedrock?
Java Edition. Every pack is made for Java, not Bedrock.
Can I edit the models?
Yes. Recolor, retexture or rework them for your project. Just don't resell or share the files.
What do I need to use them?
A Java resource pack, or a plugin like ItemsAdder or Oraxen, to load the models in-game. To change them yourself, open them in Blockbench, which is free.
